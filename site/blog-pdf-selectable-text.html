How to tell if a PDF has selectable text

A PDF can look like a page and still contain no words for a reader to work with. Here is how to tell the difference.

That distinction is easy to miss because both kinds of PDF look the same when you open them.

The quickest test

Open the PDF in a normal browser or document viewer and try to select a sentence with your mouse or finger. If individual words highlight and you can copy them into a text field, the file probably has selectable text. Try selecting across two lines as well; a useful text layer should usually follow the reading order instead of behaving like one large picture.

On a phone, press and hold on a word. If the viewer offers text selection, search, or copy, that is a good sign. If the entire page only zooms and pans as one image, the document may be scanned.

Why the text layer matters

A text layer is what allows a browser to search, copy, read aloud, translate, index, or reflow the words. Without it, the PDF viewer can display the page, but it has no reliable characters to rearrange into a responsive reading column.

A page image can show you what the document looks like. A text layer lets software understand what the document says.

Signs that a PDF is image-only

Scanned books, scanned receipts, photocopied articles, and older archival documents are common examples. The pages may have visible type, but the type is part of a raster image. Searching for a word returns nothing. Copying produces no text or a meaningless block. Zooming makes the letters larger without making them more structurally available.

What OCR changes

OCR, or optical character recognition, analyzes page images and proposes a text layer. It can make a scanned document searchable and sometimes reflowable. The quality depends on the scan, typeface, language, page damage, columns, tables, and the OCR engine. A clean printed page may work well; a skewed photocopy with footnotes and equations may not.

OCR output should be treated as an interpretation. If a name, number, quotation, or formula matters, compare it with the page image. A reader should make that boundary visible instead of silently presenting uncertain text as exact.

What Paper supports today

Paper currently works with public PDF URLs that contain selectable text. It does not OCR scanned PDFs yet. If you are not sure whether a document will work, perform the selection test first or try the link and let the reader tell you when it cannot find enough text.
