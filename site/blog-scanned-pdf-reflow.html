Why a scanned PDF may not reflow

If a document is made of page images, a reader cannot simply rearrange the words. First, it has to find them.

A scanned PDF is usually a collection of images inside a PDF container. It may show a perfectly legible page to your eyes, but the file may contain no characters, words, or paragraphs. To a reflow reader, there is nothing to wrap until another process interprets the image.

How to recognize an image-only PDF

Try selecting a sentence. If the page behaves like one picture, search for a word and returns nothing, or copy and paste produces no useful text, the document may be scanned. You can also zoom in: larger letters do not necessarily mean a text layer exists.

Some documents are mixed. A scanned cover can sit in front of text pages. A paper can contain selectable paragraphs and image-only charts. Test the part you actually need to read.

What OCR does

OCR stands for optical character recognition. It examines an image and predicts the characters represented by its shapes. The result is often added as a hidden or visible text layer so the document can be searched and copied.

OCR can be surprisingly good on clean, straight scans. It can also be wrong in ways that are hard to notice: a zero becomes an O, a footnote marker moves, a name changes, or a mathematical symbol disappears. Accuracy varies with resolution, contrast, language, page damage, typeface, columns, and tables.

OCR creates a useful hypothesis about the page. It does not turn an uncertain scan into an unquestionable source.

Why reflow makes the problem visible

A page viewer can display an image without understanding it. A reflowed view must decide where words begin and end, which lines belong together, and what order the blocks should follow. Without a text layer, it cannot do that responsibly. With a noisy OCR layer, it may produce a readable stream that quietly contains errors.

That is why a reading tool should say when it needs selectable text. A clear failure is better than a confident reconstruction that changes the document.

What to do with a scanned document

Look for an HTML, EPUB, or born-digital PDF version from the same publisher, archive, or public collection. If you create an OCR version yourself, compare important passages with the page image and keep the original source. For historical or damaged material, expect manual checking.

If the document is private, be cautious about sending it to an OCR service. A scan can contain sensitive information even when it looks harmless. Understand where the file goes and how long it is retained before choosing a tool.

Paper's current boundary

Paper currently reads public PDFs with selectable text. It does not OCR scanned PDFs yet. That limitation is intentional: the reader should not imply that it has read words that the source never exposed as text.

Check the source first, then bring Paper a text-based public PDF.
