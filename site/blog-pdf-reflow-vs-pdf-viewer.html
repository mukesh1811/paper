PDF reflow vs. a PDF viewer

One keeps the page intact. The other gives the words room to move. Knowing the difference makes it easier to choose the right tool.

A PDF viewer and a reflowed reading view can open the same source and still offer completely different experiences. That is not because one is universally better. They preserve different things.

The PDF viewer preserves the page

A conventional viewer treats the PDF as a finished visual artifact. It shows the page at a chosen scale, keeps text in its original positions, and lets you move from page to page. This is exactly what you want when the layout itself matters.

Use the viewer for forms, signatures, diagrams, page proofs, print checks, architectural drawings, detailed tables, and citations that depend on exact page numbers. It is also the safest way to inspect the source when extraction seems suspicious.

Reflow preserves the reading path

A reflowed view takes the text layer and arranges it as responsive content. Lines wrap to the screen. The reading column can stay narrow on a desktop and usable on a phone. Headings and paragraphs become the main landmarks instead of the page boundary.

That makes reflow useful when the goal is comprehension: getting through a report, following an essay, reading a public-domain book, or making a first pass through a research paper.

The viewer asks, "Where is this on the page?" Reflow asks, "How can I read this comfortably here?"

Reflow is not a PDF conversion

Reflow does not repair the source file or produce a new, perfectly equivalent document. It creates a reading layer from what the source exposes. If the PDF has no text layer, there may be nothing to reflow. If the page contains columns, figures, or equations, the extracted order can be incomplete or imperfect.

The original remains the authority. Reflow should make reading easier without pretending that a transformed view has preserved every visual relationship.

A practical two-view workflow

Start with the reflowed view when you want to understand the document. Keep the original link nearby. Switch back when a claim depends on a chart, a formula, an image, a footnote, or an exact page. Return to the reading view when the visual inspection is done and you want to continue through the argument.

This is similar to using a map and a walking path: one preserves the terrain; the other helps you move through it.

Where Paper fits

Paper is a focused reflow reader for public, selectable-text PDFs. It offers the reading surface, not an editor, annotation system, or replacement for the source viewer.
