Paper / browser PDF reader

Read a PDF online without downloading it.

When the document is already public, you should be able to go from link to reading view without first managing another file on your device.

Paper is built for the small moment after you find a useful PDF: paste its public link, let the reader fetch it, and start reading in the browser.

How the link-first flow works

1. Copy the public link

Use a normal HTTP or HTTPS URL that points to a PDF anyone with the link can access.

2. Paste it into Paper

Paper fetches the source on the server so a public document does not fail because of browser cross-origin restrictions.

3. Read in the browser

The selectable text opens in a responsive reading surface rather than a fixed page viewer.

4. Come back locally

Reading progress and preferences stay in your browser. Paper does not create a server-side reading library for you.
